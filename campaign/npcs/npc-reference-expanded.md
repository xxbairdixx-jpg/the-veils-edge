# The Veil's Edge - Expanded NPC Reference Guide

## Introduction
This comprehensive reference guide contains detailed information about all NPCs appearing in the "The Veil's Edge" D&D 5e campaign on Terminus Prime. The guide includes basic information, physical descriptions, personality traits, dialogue examples, and game statistics for each character.
