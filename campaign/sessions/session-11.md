# Session 11: The Void's Power

## Session Title and Summary
The players continue their investigation into the Void Nomads, discovering that they're using the strange lights as a power source for void magic. They must confront this while dealing with more powerful enemies.

## Session Objectives
- Investigate how the Void Nomads are using the strange lights
- Discover what they're trying to achieve
- Defend against powerful nomadic raiders

## Detailed Encounter Descriptions
