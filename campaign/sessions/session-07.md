# Session 7: The Shadow's Power

## Session Title and Summary
The players continue their investigation into the shadow cult, discovering that they're using the strange lights as a power source for dark magic. They must confront this while dealing with more powerful enemies.

## Session Objectives
- Investigate how the shadow cult is using the strange lights
- Discover what they're trying to achieve
- Defend against powerful cultists

## Detailed Encounter Descriptions

**Map:** A large chamber deep within the cave system that serves as the power source for the shadow cult. It contains glowing artifacts and magical energy.
